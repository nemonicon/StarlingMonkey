# Classic replay activation mechanism — source only

`activate.py` has **not run**. The target
`production-regression-activated-v1` and its staging directory remain absent.
No replay runner, componentizer, compiler, guest or target host runs during
activation; it only prepares a new source family for subsequent review.

The mechanism requires explicit paths and expected SHA-256 values for:

- Root's exact four actual native pins, SHA
  `c998dce40ff66a1764ad8c44f8a492b830d40bb6dce958aab711ecf3c5bcbf3e`.
- Root's native review receipt, SHA
  `1df0d5bcbb4792efa9fe7329b164aede3a2da7bc4dec6c90d011972cfb6d7f56`.
- An existing, independently reviewed activated runtime `index.json` and its
  separately supplied expected hash. Only the explicit sibling names
  `production-runtime-activated-v1` and `production-runtime-activated-v2`
  are accepted; environment-selected modules and arbitrary directories are
  refused. **The intended launch uses reviewed v2.**
- This mechanism's final source index hash, approved before invoking its main.

All four tuples, source342/recipe71b48, states, runtime source receipt, exact
runtime pin/review copies and every runtime indexed source file must agree.
The mechanism imports no artifact producer and rewrites no engine metadata.
It preserves the sealed [replay source81c](../production-regression-candidate-v1/README.md)
and [independent review747ba](../independent-production-regression-review-v1/README.md).

The generated `native-preflight.mjs` is a thin source/authority wrapper. It
hashes the fixed runtime index **before following rows or importing its entry**,
checks the same Root pin/review bytes and four tuples, then imports that exact
runtime's `classicPreflight({variant})`. Native admission and its full consumed
tool-root/artifact closure are delegated to the existing function. There is no
second 342 backend, 306 metadata projection, or invented embedding API. The
saved native recheck runs again after operations, followed by runtime-index,
authority and own-source rechecks.

All 64 inherited semantic runner/test bodies are copied byte-for-byte. Their
before/after/reverse proof record stays intact. Both original source seals
(root1777/capability1776) are inherited with local paths rebound to identical
payload bytes; actual342 and all8 LIVE WIT/adapter paths remain covered. New
authority/runtime-index/tooling evidence is added rather than substituting an
old pass. New manifest digests and the four wrapper placeholders are derived
coherently. The self wrapper is compared with its sealed template rendered
using those exact constants, avoiding a source-hash cycle. Counts after
activation are reported from the actual resulting seals, not guessed here.

The HTTP component pin stays **null and sealed**, preserving the current
fail-closed contract. Native replay and HTTP packaging can proceed after their
separate admission; host runners cannot proceed with a null component pin.
After actual packaging and independent component review, a separately reviewed
minimal host-runner activation/reseal must bind the **original actual build
family, source entry/audit paths and same component bytes**. It must not relabel
or project metadata, or repackage merely to move directories. No currently
sealed input is silently excluded to permit a later in-place pin edit.

All authority, old indices and external input bytes are checked before any
output creation and again before publishing. A fresh exclusive staging tree
preserves partial failure; an existing final or staging path refuses the run.
All generated bytes are verified before the new directory is published.
No existing candidate, accepted report or activated family is overwritten.

Ten pure source/owned-text/in-memory test groups, Python AST parsing and Node22
syntax-only parsing cover the finite authority/parser and 64-copy contract.
The runtime-receipt model in those tests uses synthetic metadata; no real
runtime index, preflight or activation positive branch is executed by them.
The producer main, new seal generation on actual runtime data, source-family
publication, source preflights and all regressions remain unexecuted.
