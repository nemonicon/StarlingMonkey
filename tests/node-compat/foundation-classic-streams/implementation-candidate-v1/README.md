This is an **UNAPPLIED, uncompiled classic-stream implementation candidate** for Node v22.14.0. It installs no live module and changes none of the current 306 native inputs, recipe869, embedding or host. The JavaScript factory is executable on the pinned Node host; native integration, component behavior, scheduler behavior and performance remain unverified.

The initial contract has the exact 24 `node:stream` names and three `node:stream/promises` names, with their bare aliases. Root default is the real callable Stream; `Stream.Stream` is itself, the five concrete constructors share its EventEmitter ancestry, and the root promises object equals promises.default. Callback pipeline/finished custom-promisify getters follow mutations of that default object while named bindings retain their initial values. The proposal supplies real finite module records to the existing native module installer; no public runtime CommonJS loader, process module/global, universal Proxy or stream global is introduced.

`classic-core.generated.mjs` contains the exact audited 24-file reachable readable-stream4.7.0 state-machine graph. Raw licensed inputs remain under `vendor/`; independently inspectable transformed inputs are under `source/readable-stream/`. A finite closure-private CJS cache is populated before each wrapper executes, preserving the original circular dependencies. Every literal dependency is resolved at generation time. Package-main/browser/environment selection and Jco's Node24 emitter Proxy layer are excluded. This is one captured JS state-machine factory over existing native byte primitives, rather than another native implementation of backpressure/event state.

The supported candidate domain covers ordinary object mode and attached, fixed, unshared byte views; read/push/unshift, write/end, pause/resume/pipe, cork/writev, construct/final/flush, destroy/error/close, basic state predicates, ordinary async iteration, callback/promise pipeline and finished, and AbortSignal cancellation. Encodings inherit the selected Buffer/StringDecoder UTF8/hex contract. Named constructor/property presence is not a claim of complete Node reflection or every overload. [api-status.json](api-status.json) records the pinned inventory and deferred methods.

Compose, duplexPair, Web conversion methods/overloads, function pipeline stages, explicit iterator options, operators and async disposal are finite own-coded throwing functions. Web Transform/pair-shaped stages are rejected before core dispatch, including objects with readable/writable fields. `asIndexedPairs` is removed because it is not a Node22 member. `node:stream/consumers` and the six legacy `_stream_*` modules are not registered by this first subset; reuse their separate audited prototypes in later stages. The existing `node:stream/web` remains a distinct bounded module, not a substitute for classic classes.

Local Node22 changes include raw byte-window treatment of DataView and other typed views, a deterministic 64 KiB byte high-water mark/16 object default, and preservation of pipeline AbortError cause. These changes are supported by the preserved pinned Node source/oracles, including [Node22 documentation](https://nodejs.org/download/release/v22.14.0/docs/api/stream.html), not the Node24 Jco adapter. The first abort-cause mismatch and a later named-helper recursion were caught on the host and preserved under `history/`; neither old path ran in a guest. Independent review then found the missing Transform/pair refusal and mutable-default getter case; their preceding source and narrower reports are also preserved.

The byte demands are already available: Buffer alloc/allocUnsafe/from/isEncoding, byte views/slices/toString and StringDecoder write/end reuse the selected implementations. BufferList.concat is its own linked-list aggregation using captured native Uint8Array.set, not the unavailable Buffer.concat or Buffer.prototype.copy. The zeroed exact-backing allocUnsafe policy and Buffer input/allocation caps remain. No new C++ copying kernel or performance benefit is inferred. Internal private primordials capture direct operations; ordinary API hooks remain observable. No complete primordial-poisoning immunity, exact error text/stack, arbitrary internal-state mutation or cross-realm claim is made.

Queue limits are explicit candidate behavior: 4,096 chunks/objects and 16 Mi nonobject state.length units. Units are bytes before decoding and UTF16 code units after decoding, so this is not a total memory bound. Writable retention is checked before pendingcb mutation; readable checks precede linked-list retention, including decoder.end. A limit error has own profile fields and requires discarding that stream. Decoding and earlier state transitions may already have occurred; full atomic rollback/recovery is not claimed. Application payloads and callbacks can consume arbitrary memory/work. The separate native FIFO retains its own 4,096 pending/1,024 arguments/65,536 aggregate-arguments/checkpoint-work limits.

It fetches no lazy module and invents no embedding API. The created function and installed constructors are held by normal JS closure/module tracing; queued callback/argument values are held by the existing traced TaskQueue FIFO. All C++ values surviving JS calls are Rooted. This is source reasoning, not compiled/GC proof.
