`fixtures/driver.cjs` is ordinary CommonJS source with `load(specifier) { return import(specifier); }`. It must be loaded by the installed `node:module` loader during the request, so the import's referrer is the genuine `JS::CompileFunction` CJS script. The probe never evaluates the driver as ESM or constructs a `Function`, changes ScriptPrivate, supplies fake module metadata, or calls private JSAPI. All eight `.cjs` files are committed Source only; no private filesystem fixture staging has occurred. A later Root-owned runtime must create a fresh independent physical copy mounted as `/probe` and authenticate it before/final. Intended0444/0555 modes are a physical policy, not proof of read-only WASI preopen rights.
