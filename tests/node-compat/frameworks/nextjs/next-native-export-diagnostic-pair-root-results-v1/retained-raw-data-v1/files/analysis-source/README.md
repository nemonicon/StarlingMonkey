# Native ordinary-success-site public-correlation analyzer Source

This is an unexecuted Source successor of the reviewed `bea8` public-correlation analyzer. It preserves its actual Playwright POST header, unique document-local NetLog POST/send-header, V2 grammar, per-lane public-enter cardinality and conservative invalid/duplicate POST checks. It adds native diagnostic parsing and one public-value/cardinality decision. The original analyzer and all prior results remain unchanged. `analyze.patch` records the exact Source delta.

Selected Source is the sealed `5d20` guest/`022f` entry, unchanged V2 `7470` marker schema, `6ed5` native Source/`d183` protocol, unchanged browser/client collectors, and the genuine `5c28` Next INIT review. The `91e9` fixed17 diagnostic review is an engine/protocol prerequisite only; none of its case counts or outcomes are projected onto the future Next pair. Historical uncompiled/NULL prose in these Source witnesses stays historical. Actual pair/runtime/capture paths, argv and results remain NULL in `plan.json` until completed data exists and Root explicitly binds the command.

The analyzer requires 33 explicit CLI files: the 14 exact Source/review pins and 19 data roles listed in `plan.json`. The future native runtime index is an explicit late file, authenticated against the actual pair plan, authority and native result rather than an old runtime index. No embedded descriptor path is opened; actual input descriptors must match supplied CLI files. All paths, file types, single links, unique inodes, individual byte bounds and the 96 MiB aggregate fence are checked before any input read. All reads and final input bookends are checked. Inputs are bounded to 8 MiB data/20 MiB per NetLog, with smaller Source and manifest limits. Nothing is imported from retained Source.

Before marker parsing, the actual original native/Stock owners must be clean, complete publications must match explicit results/terminals/authorities, native host must have planned exit zero and the native client natural zero or one. Native stdout must have complete EOF/write/sync-close/finalization metadata, no overflow/errors/unknown bytes, exact descriptor/hash/size/ceiling and the current original named-file identity. A complete capture can coexist with failed application assertions. Old gates, native raw one, Stock results and browser strict/functional results are reported unchanged.

Native ordinary records must be complete ASCII JSON lines of at most 512 bytes including LF, exact fixed schema/version/event, known enums, strict counts and copied 64-lowercase-hex values only. Native short truncation records, foreign native markers and malformed/partial native lines are retained as diagnostic loss and block the native-site join. The merged log is never partitioned into physical instances/windows by counters, token values, order or timing. The new native records contain no request/window IDs.

`native_site_join` requires the existing browser/NetLog/V2 public join and exactly one native `single-valid` POST `/actions` record with the same declared server-action public value. Any `ambiguous` record, cleared/partial/unadmitted route, or unavailable unknown POST `/actions` snapshot blocks it. Thus invalid, duplicate, nonlinear or unknown metadata cannot be defaulted to missing. Only `unavailable`/`missing`, one observation, admitted method/path and null output snapshot is source-certified missing: `d183` certifies that this shape came from strict five-primitive missing/count0/null input, although the native record's output `corrCount` remains null. It can be retained as a separate missing prior POST; it cannot supply positive evidence. Valid other values and known other routes are explicitly separate observations. A matching GET never substitutes for a POST. Two matching POST records prevent uniqueness.

The decision reports `observedNativeSuccessReturnSitePublicPostMetadataJoin` separately from `observedPublicPostMetadataJoin`. A positive value witnesses only the named ordinary native site after fulfilled/result-lowering checks and before original C return. It proves neither the C function returned nor canonical post-return, host/TCP completion, physical Store/resource/window identity, inner-fetch causality or cause. Spoofing or replay that leaves no distinguishable evidence cannot be excluded; missing observations remain unobserved and logger silence does not prove lossless observation. Current application failures are never waived.

`test-native-join.py` is optional inert Source for Root's bounded pure-decision validation after Source peer. It AST-selects the exact pinned `native_site_join` function and uses 17 handclassified public-cardinality cases; it does not invoke the analyzer, parsers or any target. R has only parsed the new files with Python AST and has not executed either file or its functions. Root owns any first seam/analyzer execution after independent Source review. No actual command is issued in this Source packet.
