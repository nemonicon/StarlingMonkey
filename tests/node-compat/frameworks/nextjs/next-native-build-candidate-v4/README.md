This is a dormant disk-frugal successor to the actual V3 Next native builder. It
has not copied a source tree, configured a project, run Cargo/Rustup/a compiler,
linked an engine, or executed an engine/guest. Root must issue the complete late
inputs in root-authority.template.json. NULL fields are deliberately not usable.
No old frontend result is accepted as a V7 frontend proof.

must be disjoint. Root's composition, rather than this caller, supplies the five

at an existing native path, so it does not increase 435. The 824-file portable

modes must match the expected inventory before any copy/action. Runtime initial
identities are then held byte-for-byte through every phase and a final recheck,
including failure. Directory symlinks are not followed; absolute, escaping,
broken and external links refuse. The original V5 tool archive identities and
actual extraction record are retained. A new whole-tree current bookend is not
an invented attestation that the original extraction authenticated every tree
