## Identity, thenables and bounds

The namespace exposes only `default` and the engine's normal namespace metadata. `namespace.default` is the exact returned CommonJS value, including a class/function/primitive, without adding `__esModule` or synthesizing named exports. An export object's own `then` getter is not copied into a namespace export, so the loader creates no accidental namespace thenable. Next's own `.then(mod => mod.default || mod)` can intentionally assimilate a thenable export; arbitrary thenable handlers are outside this first consumer profile.

Canonical URL aliases share one synthetic record per JS runtime; different runtimes/host instances do not share this cache. Ordinary mutation of the exported object remains visible through the same reference. The default binding is a snapshot of the CommonJS value at first import, not a live read of later `module.exports` replacement. ESM wrapper identity survives public require.cache deletion; exact Node22 mutation/deletion behavior needs the declared future differential before a parity claim. No application or guest-global Map is added.

Bound new canonical records at8192 (same scale as the actual CommonJS MAX_MODULES), URL/path at4096 UTF8 bytes plus the existing JS path bound, and one in-progress load per canonical key. Increment accounting only after successful registry publication. Ordinary recursive/in-progress CommonJS dynamic import is a coded profile refusal initially; do not publish partial exports as a successful completed wrapper. Reentrant require hooks, failure cleanup and existing loading-module detection need a concrete Source review before implementation is accepted. Do not infer registry activity or native resource identity from public Module fields.

All JS values spanning allocation/calls are `JS::Rooted*` / `JS::Handle*`, including records, methods, URL/path/key strings, require function, exports and module. Use `JS::RootedValueArray` for arguments and the existing PersistentRooted moduleRegistry for retention. Own encoded native path bytes across calls/GC. Do not keep borrowed ArrayBuffer/string pointers, untraced C++ JSValue containers or cross-realm wrappers without an explicit existing wrapping/realm check. Phase guards must precede cached-record returns too; caching cannot enable INIT filesystem imports.
