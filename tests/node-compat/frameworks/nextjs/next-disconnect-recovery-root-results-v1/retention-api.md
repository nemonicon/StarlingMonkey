# Disconnect/recovery retained packet

Root invokes `python -I -B retain-results.py BINDINGS_PATH BINDINGS_SHA REVIEW_PATH REVIEW_SHA` only after the original fixed slots are closed or their suffix is explicitly unattempted. The source refuses optimized/nonisolated/bytecode-writing modes before input IO and requires fresh exclusive `raw-records`. It never starts or queries a host.

The input review is `ROOT_DISCONNECT_RECOVERY_DATA_REVIEW_COMPLETED_V1`: `reviewedInputs` lists every exact reviewer raw-read tuple; `actualReviewer` is retained as Source. `allFunctionalRecoveryPassed`, `guestAbortDiagnosticsPresent` and `nativeLifecycleAccepted:false` remain separate. A client pass cannot waive native abort/backtrace diagnostics. All present original generic owner terminals must have known clean process-group quiescence before any owned output is walked. An existing owner namespace without its terminal refuses retention. An unattempted fixed suffix requires absent owner/output namespaces, explicit review `missingOrUnattempted` DATA and final absence bookends; it creates no call or owner evidence. A closed attempted actor that created no output retains its owner/failure records and an explicit omission.

All exact reviewed inputs, issued authorities/preparations, closed original owner directories, owned client call JSON/body/publication files and root host logs are retained, including negative and partial observations. The three small runtime/client/documentary-browser Source families and selected prerequisite proof JSON are retained. Full copied apps, project/cache/XDG trees, compiler/SDK/tool/native/component binaries and the large protected input closure are omitted; the index records this scope. Browser Source retention does not imply browser invocation.

The packet uses the prior portable schema: `entries[]` has `source:{path,sha256,bytes}`, `retained:{path,sha256,bytes}`, `encoding` (`identity` or deterministic `gzip`), `reasons` and `reviewedInput`. Source tuples describe expanded bytes. Original paths are lookup keys for a future saved checker, never its IO destinations. The index is `DISCONNECT_RECOVERY_CLOSED_RESULTS_RETAINED_DATA_V1` with `runtimeBindings`, `actualReview`, `originalOwners`, `unattemptedArms`, counts/bounds/omissions and the actual separate review flags.

Bounds stay 4096 files, 32 MiB per expanded file, 384 MiB expanded total, 256 MiB stored total and depth16. Text at least64 KiB uses gzip level9 with empty filename and mtime0. Every copy is newly created/fsynced/closed/read back, nlink1, a distinct inode from its original and all other copies; original files/directories/absent namespaces receive final bookends. The index has a4 MiB bound. This records public local observations, not remote EOF, guest cancellation, resource retirement or same-Store identity.
