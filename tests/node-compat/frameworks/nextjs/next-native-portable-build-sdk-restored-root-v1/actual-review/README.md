The actual full native build passed all six commands and its original Root owner. This folder retains the complete finite text receipts, including the earlier SDK admission failure. It does not execute or accept an engine, component, imports, guest workload or deployment.

Run the portable reader from any checkout:

```sh
python3 tests/node-compat/frameworks/nextjs/next-native-portable-build-sdk-restored-root-v1/actual-review/check.py
```

`--current` additionally rehashes the original 2,502 **text records** at their recorded paths. Neither mode reads the engine, native objects/static archives, tool trees, OpenSSL tree, restored vendor/FFI payloads or the 825 copied source payloads. The default works without those private paths. It only reads this folder's retained DATA.

`payload-index.json` maps every regular TAR member to its unchanged original absolute path, SHA256, byte size and file mode. `data.tar.gz` contains 23,567,578 expanded bytes, compressed to 3,177,229 bytes. No signed download URL, application encryption key or binary payload is included. The TAR is read without extraction; the reader refuses extra, missing, duplicate, unsafe, nonregular, wrongly sized or wrongly hashed members.
