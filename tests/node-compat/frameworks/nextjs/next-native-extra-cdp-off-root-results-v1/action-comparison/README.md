The native-off action remains a strict failure. All four runs passed both functional browser interactions; the three stock off controls also passed every browser error gate. Native-off retained request7 `net::ERR_ABORTED` and the three body/finished/sizes errors. Disabling the additional CDP session is therefore not sufficient to remove this native failure. It does not establish a unique cause or accept any earlier failed run.

It copies no app/package/response/source payloads. B authored the observer/actor controls; this is bounded analysis, not an independent whole-runtime acceptance review. No actor, retry, workload or test ran for this analysis.
