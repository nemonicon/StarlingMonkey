# Isolated structured-stacktrace collector

Dormant source for three ordinary HTTP GETs against the exact separately constructed stacktrace probe. Root must fill and review the authority template, then run `python3 -I -B run-owned.py ROOT_AUTHORITY.json`. This preparation performs no constructor, oracle, component or host invocation.

The original 0af monitor bounds the Node collector to 180 seconds. It leases one loopback port, starts pinned stock Wasmtime 42 with reuse 32 / idle 60 seconds, grants no filesystem preopens or app mount, retains all three HTTP bodies before parsing oracle JSON, and requests an owned SIGINT shutdown. It authenticates its closed source family, five fixed source families, tools/native inputs and actual late artifacts before and after. The exact constructor, input entry/source, component audit, 13-interface allowlist and incoming-handler export remain checked.

`comparison.mjs` compares the four cases' capture/own-stack descriptors, lazy hook/event ordering, callback count and target identity, array/string kinds, CallSite method and return types, positive line/column values, throwing callback identity and exact depd location success. Exact stack text, paths, positive line/column numbers, function-name text and frame counts are deliberately not compared because Node and guest call paths differ. Full original payloads remain retained. Frames still require method shapes and positive line/column semantics; limits/truncation are visible.

A complete captured and cleaned-up semantic mismatch may set `observationsValid: true`; it MUST set `nodeSelectedParity: false` and exit 1 at both Node collector and outer wrapper. No expected-gap exception or full Node/Next acceptance is granted. Malformed or missing records fail observation validation. The pure tests consume Root's already retained Node JSON only; they do not execute the fixture or oracle.

All Root/actual artifact fields in the source plan/template remain null. Exact outputs use the authority's fresh runId; no existing run is resumed. All broader application, deployment and adoption claims remain false.
