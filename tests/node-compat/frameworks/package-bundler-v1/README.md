# Production CommonJS packaging audit v1

This packet records **host-only** API/source inspection and bounded toy-module experiments using Node22.14.0 and Rolldown1.2.16. It does not approve a production bundler, execute a framework package or run a native-profile engine, Wasm guest or component. Root owns the separately implemented optional `framework-package-bundler.mjs` and its later real framework/component tests. The old finite profile bundler is unchanged.

The retained experiments make29 build attempts and13 fresh host toy-module executions. Generated modules contain only the controlled fixtures and ordinary Node Buffer/Stream namespace identity checks; no Buffer byte kernel, codec, key operation or framework implementation is executed. All inputs, generated code, error messages and host stdout/stderr are present in the evidence directories. These are finite examples, not a proof of arbitrary CommonJS equivalence.

Native identity above is measured against **host Node namespaces**. Node's complete Buffer/Stream namespace inventory is not transferred to the bounded guest profile. A real native-profile component must independently test its selected default/alias/global relationships and final imports.

The pinned local type declarations establish these real options: `transform.define`, `resolve.mainFields`, `resolve.conditionNames`, `platform`, `output.externalLiveBindings`, `output.paths` and `codeSplitting:false`. Built-in transformation occurs after plugin transform hooks. Neutral resolution has no default main fields; choose the package entry/conditions deliberately. The exact source declarations and their hashes are in `provenance.json`. The [official plugin documentation](https://rolldown.rs/builtin-plugins/esm-external-require) also describes exclusive external ownership and the generic ESM fallback; the pinned experiments determine the behavior claimed here.

The old `createProfilePlugin` is a finite hand-written `.cjs` wrapper that rewrites only selected native requires. Relaxing a guard does not turn it into a general package CommonJS converter: it changes parser identity, default-only interop and scope bindings before Rolldown gets to classify the source. Keep the old API unchanged and give general package packaging a separately named policy and result version.

The source contract requires the selected actual native manifests to drive admission, canonical native imports to remain external, no builtin JS adapter substitution, one ESM chunk, complete final-code parsing and explicit rejection of unresolved runtime loaders/environment. Native namespace hoisting is acceptable only as access to already installed builtin bindings with no newly performed host operation. Package conditional execution must retain its lazy cache semantics; these two controls do not prove all side-effect/cycle cases. No generic ESM external namespace-copy behavior should be silently substituted for the selected native CJS default.

Tests still required on the **actual optional implementation** are listed in `fixture-suggestions.json`: actual package source resolution/production choices; all selected native aliases/default/global identity in a real component; adversarial loader/reference paths; no-adapter graph checks; exact generated virtual-source provenance; init/deployed outcomes; complete retained Jco/stock-Wasmtime returns; and same-source Node comparisons. The mutable package named-binding difference remains explicit. React/Next successes or breakages must come from later actual runs, with their standard-WASI import audits and initialization/capability limits. This audit supplies no action, runtime, adoption or security-completeness grant.
