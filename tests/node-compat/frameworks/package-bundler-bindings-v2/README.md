# Pure lexical reference helper v2

[bindings.mjs](bindings.mjs) exports `findUnboundReferences(ast, names)`. The input is an actual Oxc/ESTree `Program`; `names` is a Set or array of strings. The return is an array of the **original Identifier nodes** which reference one of those names without a lexical binding. Their `.name`, `.start` and `.end` remain the parser's values. The input is not mutated, code is not evaluated, and no host or guest API is supplied.

The analyzer collects reference/scope pairs and resolves them after all declarations are collected, so var/function hoisting and forward lexical declarations work. TDZ references are considered bound: this helper distinguishes ambient absence, not initialization safety. Function parameter/default scopes are separate from body var/function bindings. Patterns, import locals, catch bindings, lexical blocks, loop headers, switch cases, class names, methods, fields and isolated class static blocks have explicit handling. Named function/class expressions bind their own name only internally. Normal functions bind `arguments`; arrows inherit it. Noncomputed property/member keys, labels, private names and external re-export names are not references; shorthand values, computed keys and assignment targets are.

[test.mjs](test.mjs) uses the pinned Rolldown1.2.16 Oxc parser under Node22.14.0. All60 synthetic cases pass with exact expected references, actual parser ranges, Set/array equivalence and full AST non-mutation checks. It parses the actual installed React19.3.1 production file as DATA and retains its three genuinely unbound `process` references in error reporting. The real ReactDOM edge production file contains zero such references. Neither library is imported or executed. A local function/parameter named `process` is tested synthetically; no nonexistent renderer-local binding is claimed.

This is a lexical helper, not a sandbox or a full JavaScript semantic analysis. The target is ordinary lowered JavaScript from the pinned parser, principally generated ESM. It does not model sloppy-script Annex B block-function leakage, runtime eval-created bindings, TDZ/control flow, global-object property aliases or whether a global exists at runtime. `with`, JSX and TypeScript nodes are rejected. The caller owns the selected names and any guarded optional-global policy; `typeof process` is still returned as an unbound reference. Known `globalThis` member and module-loader restrictions belong to the separate package policy, not this helper.

The old optional package-bundler source576 and its [HOLD](../package-bundler-implementation-review-v1/README.md) remain unchanged. This source does not approve that implementation, a successor implementation, general CommonJS/Node parity, a React/Next guest or any runtime action. Root will independently review the helper and integrate it in a distinct successor. No componentizer, native compiler, native engine, framework module or guest has run in this preparation.
