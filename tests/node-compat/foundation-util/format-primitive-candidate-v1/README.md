## Exact supported contract

- Operands are primitive string, number, boolean, null or undefined. `%s`, `%d`
  and `%%` follow Node22's actual inspect.js:2247 parser. No args returns `''`.
  A sole string is returned unchanged, including `'%%'` and unused directives.
  With extra arguments, `%%` collapses without consuming; missing directives
  remain literal, unknown directives remain text, and remaining primitive
  operands join with spaces. A non-string first operand is joined likewise.
- `%d` uses captured Number conversion of the selected primitives; `%s` renders
  numbers through Node's primitive number helper and other selected primitives
  through captured String. Negative zero, NaN, infinities, Unicode/surrogates,
  numeric strings, null/boolean/undefined conversions and partitioned percent
  sequences are included in the actual host differential.
- Live `inspect.defaultOptions.numericSeparator` is honored via the actual
  small Node number helpers, including true-mode negative-zero/exponent quirks.
  Primitive non-string joins also honor colors using the existing meaningful
  inspect.styles/colors objects. `%s`/`%d` remain uncolored exactly as Node.
  Palette properties retain ordinary JS access semantics; this is not a sandbox
  or a claim that arbitrary mutated palette accessors cannot execute user code.
- Objects, functions, BigInt, Symbol, consuming `%i/%f/%j/%o/%O/%c`, constructor
  calls, formatWithOptions and object inspection remain explicitly unsupported.
  Input types are checked before coercion; no input object's hooks or
  inspect.custom are called. Missing unsupported directives still remain literal
  when Node would not consume an argument. Other unsupported util exports and
  the callable inspect function keep their real deferred behavior.
- Caps are32 arguments,16,384 UTF16 code units per string,65,536 aggregate input
  string code units and65,536 output code units. These are JS code-unit bounds,
  not UTF8 byte or total VM-allocation guarantees. Limits throw a real
  RangeError with `ERR_SM_NODE_UTIL_FORMAT_LIMIT`; unsupported shapes throw the
  existing `ERR_SM_NODE_UNSUPPORTED`. Both retain own module/operation/profile
  fields; limits add `limit`, deferred format errors add `reason`. Error text,
  precedence and construction differ from unrestricted Node by declared policy.

The original `inspect` palettes/options remain meaningful metadata; supporting
primitive formatting does not pretend to implement its object renderer.
Default.format and named format are the same function; util/sys retain the
same declared inventory and native registration record/default relationships.
This candidate does not silently compose the separate namespace-loader proposal
or claim new per-specifier namespace object identity.
