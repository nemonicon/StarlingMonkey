# Link1 Release-GC diagnostic: independent verification

This packet independently hashes existing GC build/component evidence. It
imports no candidate preflight or packager and runs no compiler, guest, Node
oracle, host command or component. Latest production acceptance remains v11.
The ordinary verification packet is rehashed unchanged, never rewritten or
reused as the GC runtime result.

The fixed GC engine is `949d24f653903923bb7055c441b7a5131922a787d94465f014d62a8d680b802b`,
9,766,466 bytes, metadata `23e2e4d6…`, recipe `24e5dc9a…`, frozen receipt
`b170ea87…`. The source-defined report state retains `ordinary` to mean Release;
GC selection is proved separately by the GC sidecar, label-specific frozen

spawned LLD arguments, thread counts and resource benefits remain unobserved.
Only frozen GC configuration, command and wrapper copies are dereferenced.
The build log and launch stdout are separately bound as recorded provenance.

The driver32 input closure includes the exact LIVE Preview1 adapter. Ten
components with generated cores/modules/declarations, their sources and15

replay. Fatal traps do not expose their original cause.

exhaustive tracing and allocator recovery are not proved. Reset, request

priority, ALS and production admission remain open.
