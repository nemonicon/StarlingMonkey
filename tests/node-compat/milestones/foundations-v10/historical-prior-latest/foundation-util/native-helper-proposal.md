# SM147 predicate helper opportunities

This is a source-reviewed proposal, **uncompiled and untested**. The first bounded candidate uses the independently tested existing-native-intrinsic JS references. C++ additions require separate actual-component evidence and a size/cost justification.

| Predicate family | Actual API / source | Candidate boundary |
| --- | --- | --- |
| Arguments, boxed Number/String/Boolean/BigInt, Date, RegExp, Map, Set, their iterators, native Error, Promise | `JS::GetBuiltinClass` in `js/public/Object.h`, `js::ESClass` in `js/public/Class.h`; implementation `js/src/jsfriendapi.cpp:236` | Root the object; switch only actual enum members. Symbol/WeakSet/generator/module-namespace are not enum members. Intrinsic prototype cases require Node differential validation. |
| Scripted Proxy | `js::IsScriptedProxy` in released `js/Proxy.h:586` | Pinned friend API; tests the handler kind without exposing the target. Pre-reject scripted proxies before **every nonproxy** helper, including revoked proxies. Internal wrappers are a distinct case. |
| ArrayBuffer / shared / views / concrete typed arrays | `JS::IsArrayBufferObject`, `JS::IsSharedArrayBufferObject`, `JS_IsArrayBufferViewObject`, `JS_IsTypedArrayObject`, `JS_GetArrayBufferViewType` | Apply type accessors only after a successful brand guard. Classification remains true for valid detached/OOB views; never borrow data or infer type from byte length. |
| Promise / WeakMap | `JS::IsPromiseObject` in `js/Promise.h:374`; `JS::IsWeakMapObject` in `js/WeakMap.h:20` | No `.then` or key/content read. Check wrapper/realm behavior in actual components. |
| CryptoKey, optional | `CryptoKey::is_instance` inherited from `include/builtin.h:263`, class declared in `builtins/web/crypto/crypto-key.h` | Requires explicit `builtin_web_crypto` availability/dependency, or remains a deferred callable. A class-only check needs no host entropy; linking may retain guest code and must be measured. |
| Symbol objects / WeakSet | Captured Symbol `valueOf` / WeakSet `has`, with object guard | Current JS reference path uses actual intrinsic brand checks; wrong-brand TypeError allocation and error handling differ from an allocation-free native test. No private class-layout shortcut has been established. |

The [pinned public Object header](https://github.com/bytecodealliance/firefox/blob/9dab3d6f643e926a340c391ea30968e940390dec/js/public/Object.h), [actual classification implementation](https://github.com/bytecodealliance/firefox/blob/9dab3d6f643e926a340c391ea30968e940390dec/js/src/jsfriendapi.cpp), [typed-data API](https://github.com/bytecodealliance/firefox/blob/9dab3d6f643e926a340c391ea30968e940390dec/js/public/experimental/TypedData.h) and [scripted Proxy handler](https://github.com/bytecodealliance/firefox/blob/9dab3d6f643e926a340c391ea30968e940390dec/js/src/proxy/ScriptedProxyHandler.cpp) are the source basis. The handler's `getBuiltinClass` returns Other, but an explicit scripted-proxy gate avoids forwarding through any other candidate API. A successful public predicate must not run proxy traps or application-controlled `Symbol.toStringTag` getters.

Root arguments/results normally; do not hold a raw JSObject across a fallible helper that may collect or report an error. These classification operations require no byte pointers, allocation ownership transfer or live-handle access. An enum result/private helper object should stay inside the existing guest facade registration graph. It is not a host interface. No new Rust or external library is needed for this proposal.

No matching released helper was established for async-function kind, generator-function/object kind or module-namespace branding. Public `JS_ObjectIsFunction` identifies functions but not those subkinds. `Object.prototype.toString`, changed prototypes and string parsing are not robust substitutes. Node External and KeyObject types also have no current Starling representation. These six API bindings remain explicit callable stubs; adding engine-private hooks or a custom SpiderMonkey build is a separate decision, not a condition of the first bounded milestone.

Before adopting a helper, run the pinned class/prototype/proxy/revoked/spoof/realm and detached/RAB/SAB corpus in real Release components, preserving meaningful booleans and error behavior. Compare final component bytes/startup/throughput against the independently correct intrinsic implementation for shared inputs. Do not infer predicate performance from the byte-codec Weval results. Existing stopped fault work is not reopened by this proposal.
