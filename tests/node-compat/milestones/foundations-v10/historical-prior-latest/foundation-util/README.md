# Bounded Node22 util foundation

The optional **m0.7 util/types/sys builtin now passes installed-component gates** on frozen v7 OFF engine `ee92d5d4…`, with zero imports. It implements 29 captured-intrinsic predicates and selected pure utilities; 41 util callables and 13 predicates remain explicit deferred operations. It is not complete util or Node compatibility.

The audit pins Node **v22.14.0**, commit `5d2feb257bcee090e57900eb51720171a6aa92f3`. The historical [API proposal](api-proposal.json) records all 89 named bindings and their source-stage unselected status, strategy, capability boundary and validation requirements; later execution evidence below supersedes that preparation status. [Source audit](source-audit.json) hashes the inspected Jco, unenv, SpiderMonkey and integration files; [Node source ledger](node-source-inventory.json) hashes 31 official source/test files. Unsupported operations are real callable bindings, rather than empty objects or universal Proxies.

## Exact surface and existing adapters

The [public Node inventory](node-inventory.json) confirms **47 named util exports plus default**, and **42 util/types predicates plus default**. Bare/prefixed aliases share Node namespaces. util's `types` is the util/types default; named bindings initially equal default properties; `debug===debuglog`. `inspect.custom` and `promisify.custom` are real global-registry Symbols, with Node's writable/enumerable/configurable public properties. Inspection colors/styles/defaults are meaningful data, including alias getters and palette null prototypes. No top-level scalar constant substitutes for the types object.

[sys inventory](sys-inventory.json) and its [source ledger](sys-source-inventory.json) confirm that sys has a **distinct namespace from util**, while sharing every export value, default and CommonJS object. Each fresh Node first load emits one `DEP0025` warning; aliases/cache hits add none. The prototype deliberately omits warning delivery, keeping zero imports. A production profile must declare this partial behavior or select a guest warning/standard-output policy; it must not silently claim Node warning semantics.

Jco 1.40's `createUtilBuiltin` in `dist/node-builtins/util.js` calls `stdModule`, whose default resolves **jco-std 0.10 / Node24.x.x / WASI0.2.x** util and util-types. Its test exercises algorithms and namespaces without util-specific WIT requirements. This is not the older unenv util implementation. Node24-only exports such as `diff`, `setTraceSigInt`, `convertProcessSignalToExitCode` and `isFloat16Array` must not enter the Node22 manifest. The separate unenv 2.0.0-rc.24 source contains source-visible approximations: boxed-object predicates use primitive `typeof`, several checks use `instanceof`, inspection/deep comparison use JSON, and the custom promisify symbol is not Node's registry key. Neither adapter is an unexamined Node22 contract. [Jco adapter source](https://github.com/bytecodealliance/jco/blob/jco-v1.40.0/packages/jco/src/node-builtins/util.ts), [pinned Node API](https://nodejs.org/download/release/v22.14.0/docs/api/util.html).

## First bounded candidate

The selected direction is **29 predicates using existing native ECMAScript intrinsics**, plus `inherits`, bounded `promisify`, `toUSVString`, and exact aliases to the installed global TextEncoder/TextDecoder. Remaining util functions and 13 predicates are explicit versioned deferred callables. Supported text constructors retain their existing Web codec limits/deviations; this does not add Node-only encodings. Predicate fixtures do not consult application-controlled tags, `instanceof`, proxy targets or byte data. Capturing primitive methods before application code prevents later prototype replacement from changing the checks. `isDataView` uses view branding rather than reading a potentially detached/OOB `byteLength`.

The 29 predicates are enumerated in [prototype scope](prototype-scope.json); the [real ESM sources](util-prototype.mjs) export the entire pinned inventory. A separate [types source](types-prototype.mjs) supplies one ordinary default object and named cells. The sys source reexports the same values from a distinct module. `inspect` remains callable-unsupported while its symbols, palettes and live default-option object remain inspectable. Private promisify symbol capture is independent of writes to its public `.custom` field. Two truthy custom-property reads, descriptor/prototype preservation, callback/throw identity and first settlement follow the pinned Node implementation. Private Node custom-argument annotations, warning emission and exact generated error messages remain outside this bounded contract.

Further utility APIs are not blocked merely by host capability:

- `parseEnv(content)` is a pure parser; it must not import or mutate environment state. `parseArgs` with explicit args can also be pure, while omitted argv needs an explicitly selected `wasi:cli/environment@0.2.10` policy or refusal.
- `styleText` with explicit nonstream validation can be pure; default stream/TTY/color behavior differs by release and must be scoped. Inspect/format/deep comparison require substantial semantics, not JSON substitutes. Current bounded native Assert also defers deep comparison.
- Existing web `parse_mime_type` simply splits parameters by semicolons; it cannot replace MIMEType's quoted grammar, mutation and serialization contract.
- `callbackify` needs Node nextTick ordering/error/context behavior. Jco's portable stream scheduler drains a `queueMicrotask` queue; copying it is not a proof of Node scheduling equivalence. `aborted` additionally needs weak listener/resource/snapshot cleanup tests.
- Logging, environment-sensitive debug output, warnings and wall-clock timestamps need separately selected standard interfaces. Node PID/signals/libuv errno tables do not appear automatically from WASI. System-error APIs remain deferred until an explicit guest OS/table policy exists. Transferable AbortSignal hooks are absent from current clone callbacks and cannot be replaced by ordinary controllers.

The actual locked readable-stream 4.7 core uses its own `lib/ours/util.js` helpers rather than requiring this entire public util surface. Jco stream lifecycle hooks use `Symbol.for('nodejs.util.promisify.custom')`; that exact interoperable symbol matters. Do not import Jco util wholesale merely to satisfy streams, or claim util alone establishes Node stream compatibility. Pure helpers should not force process/stdio/clock/entropy/filesystem imports.

## Native helper opportunities, not compiled claims

[Native helper proposal](native-helper-proposal.md) cites actual SM147 APIs. There are **35 core predicate candidates plus optional CryptoKey** using existing APIs/intrinsics. The first candidate deliberately keeps the tested 29 intrinsic references; six additional core brands (Arguments, MapIterator, SetIterator, native Error, Promise, scripted Proxy) remain deferred pending actual helper/component gates. Async/generator/module-namespace/external/KeyObject classification is also deferred. No private layout, invented embedding API or generic tag heuristic is proposed.

CryptoKey branding would require an **explicit existing `builtin_web_crypto` target dependency**, an optional scope choice and size/import measurement. A type predicate must not silently retain unrelated crypto code or enable entropy. With that option absent, its binding remains a deterministic deferred callable. Any later helper must pre-reject scripted proxies for nonproxy checks, root fallible object operations and classify detached/RAB/SAB views without borrowing their data.

## Verified prototype evidence

[Node prototype results](prototype-results.json) pass **3,614 checks**: 29 independently implemented predicates over 107 public inputs, plus namespace/metadata/aliases, inherits, ToUSV conversion, promisify and deferred call/new contracts. Inputs include boxed/prototype forgeries, subclass and cross-realm objects, proxy/revoked-proxy values, throwing tag getters, detached/OOB/resizable/shared views and prototype poisoning. No Node predicate was used as a hidden implementation delegate.

The [actual component proof](component-results.json) uses frozen v6 OFF engine `33b9cb24…`, all 285 source inputs, the audited v2 componentizer and exact repository Preview1 adapter. Component SHA `f969f5acc53f60e6faf9d1d550095fa21c359194b6fa7a074e76a0ef5d54e0d8` (12,129,296 bytes) has **zero imports** and passes two retained Jco calls plus a fresh Wasmtime 42 call. Every call passes **2,436 shared checks**, including 29 predicates over 80 portable inputs, plus **108 deferred call/construction checks**. Four top-level unsupported operations genuinely fail componentization. Installed native text-constructor identities and snapshot/default/sys graphs survive reuse. [Evidence receipt](evidence-receipt.json) preserves raw report/source hashes.

**Target limits:** SharedArrayBuffer's constructor is absent, so no target SAB fixture ran; transfer and resizable-buffer fixtures did run. No portable cross-realm factory is installed, so Node-only realm tests do not prove SpiderMonkey wrapper behavior. This bundles local explicit ESM prototype modules; it is not native builtin registration, selected `node:util` resolution or CommonJS admission proof. The initial failed attempt was a prepackaging JSON parser/carrier mismatch; an equality-checked equivalent ESM scope carrier fixed the fixture, without changing production code. No DEBUG, fault injection, private guest-memory observation or host change was used.

After root review, production preparation can reuse the existing strict `evaluate_factory` and `Engine::define_builtin_module` mechanisms, with an optional default-OFF selection and explicit Node22 export manifest. The factory should return finite `{root,types}` export records; util/sys share record values while retaining distinct module namespaces. Static literal CommonJS lowering and canonical aliases require actual selected-manifest component tests after registration. Mutable default properties do not rewrite ESM cells; runtime require/syncBuiltinESMExports remain outside the current bundler contract. No production selection or complete util compatibility is claimed by this prototype.

## Prepared production sources, integration pending

The approved bounded direction is now prepared as nine **new** files under `builtins/node-compat`: `util.mjs`, `util-types.mjs`, `util-core.mjs`, `util-metadata.mjs`, `util-unsupported.mjs`, `LICENSE.util`, `export-manifest.util.node-v22.14.0.json`, `generate-util-factories.mjs` and `util-factories.generated.h`. Profile version is **m0.7**; the intended `NODE_COMPAT_UTIL` selection defaults OFF. No shared registration, CMake, common generator, build recipe or module-admission file was edited by this work.

`kUtilFactorySource` takes one private **undefined** argument, needs no Buffer, and returns finite frozen `{root,types}` records. Register `graph.root` for util/sys spellings and `graph.types` for util/types spellings. `root.types===types.default`; default objects stay ordinary mutable Node-style objects while internal export records are frozen/null-prototype. Existing native text constructors are required; no optional crypto class/target or new host interface is referenced.

[Production source gates](production-source-results.json) pass **2,523 shared checks and 108 deferred call/new checks** for both canonical ESM and the generated factory. The test evaluates the latter with script-level strict mode, matching `evaluate_factory`'s actual `setForceStrictMode`, including ordinary receiver behavior. Additional production hardening captures Error/TypeError, property definitions and default-option assignment, and avoids an inherited `Error.code` setter or replaced globals. This changes error-path robustness beyond the isolated prototype without adopting any new API. Node error text/arity/prototype details outside the stated scope remain deviations.

Those were host-source/factory proofs; installed builtin and CommonJS gates were pending at that stage and are reported separately below. The earlier local ESM component proof is preserved byte-for-byte and is not relabelled as an installed builtin test.
